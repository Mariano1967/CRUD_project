Este projecto se basa en una hoja para capturar datos de posibles miembros creo que no require mucha explicacion aunque es un poco minucioso.
El usuario ingresa los datos.
El usuario recibe un mensaje si ingreso todos los datos.
Despues el usuario puede editar o borrar los datos y los datos se traen a la forma de arriba si se ingresaron recibira un mensaje y los datos se actualizaran.
Si no los ingresa recibira otro mensaje.
Si desea borrar los datos en el LOcalStore entonces tiene que picar en borrar y tambien recibira un mensaje para ver si esta seguro que los quiere borrar.
